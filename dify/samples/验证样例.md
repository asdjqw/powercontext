# 验证样例：记忆酒馆

完整、可执行的验证样例见 [`../VALIDATION.md`](../VALIDATION.md)（初始状态、输入顺序、预期表现、实测结果、恢复方式）。

## 运行环境

- **主路径**：Dify **0.15.3** + `app.dsl.yml`（`version: 0.1.5`）+ PowerContext 1.2.0 桥接；
- **备选**：Dify **1.18** + `app-1.18.dsl.yml`（`version: 0.7.0`，需 `openai_api_compatible` 插件）。

## 快速步骤

1. 启动桥接：`cd dify/bridge && pip install -r requirements.txt && python app.py`（8099）；
2. 启动 Dify 0.15.3（见 README 5.1），然后
   `DIFY_BASE=http://127.0.0.1:5001 MINIMAX_API_KEY=<key> python scripts/setup_0.15.3.py app.dsl.yml`；
3. 打开应用入口 `http://<dify-host>/app/<app_id>`，按 `VALIDATION.md` 的三轮输入体验；
4. 对照实测证据：`verify/dify_session.json`、`verify/workflow_nodes.json`、`verify/bridge_memories.json`。

## 判定口径

- 第 1 轮（新会话）不知道具体身份，只给氛围与线索；
- 第 2 轮（**新会话、同 user**）能复述第 1 轮的问题（“戴面具的人”），且 `conversation_id` 不同；
- 第 3 轮（同会话）延续场景；
- 换 `user` 后不再认识你（scope 隔离）。
